# Star Fox Adventures: Discord Rich Presence Mod

A Discord Rich Presence mod for **Star Fox Adventures** running through **Foxhollow**.

The mod updates Discord with your current location or activity and playable character.

## Supported platforms

- Windows x64
- Linux x64
- macOS


## Requirements

- Foxhollow 1.0.20 or newer
- Discord desktop client

## Installation

Download either directly through the Foxhollow Launcher, or get the mod from GitHub Releases.

1. Download the most recent release ZIP.
2. Extract the `sfa-rich-presence` folder into your Foxhollow Launcher `mods` directory.
3. Start Discord.
4. Launch Star Fox Adventures through Foxhollow.

Discord should show **Star Fox Adventures** as your activity once the game is running.
